Sorts tracks by key using Camelot Wheel notation, first translating keys
(A#m -> 3A) and then ordering them. Note there is no way to sort tracks
by Key using standard title formatting since keys don't follow an ordered
set with numbers and letters which may be naturally sorted in some
notations.

Supports Camelot Keys, Open Keys and Standard notation, so as long as the
key tag is filled with any of those, it should work. Even if different
tracks use different key notation. Note the key tag can be remapped at
the menus.
